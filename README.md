Mathematical Tools Using Python

Author: Muhammad Nuhu

About the Project

Mathematical Tools Using Python is a collection of Python functions designed to perform mathematical calculations and basic statistical analysis.

The project aims to explore how programming can be used to solve mathematical problems and support data analysis.

Current Features

- Calculate the arithmetic mean.
- Calculate the median.
- Calculate population standard deviation.

Technology Used

- Python 3
- Python Standard Library

How to Run

1. Download or clone this repository.
2. Make sure Python 3 is installed.
3. Open a terminal in the project folder.
4. Run:

python math_tools.py

Future Improvements

- Add mode calculations.
- Introduce differential equation solvers.
- Explore graph theory algorithms.
- Add mathematical visualisations.
